# Nexum · Spin Builder

Web para diseñar clases de ciclo indoor: detección de BPM y masterbeats, gráfica por zonas (Z1–Z5), cadencia por punto (BPM × factor), mezclas con fundidos, recortes y cambio de velocidad.

- `index.html`: la aplicación completa (una sola página, sin build).
- `netlify.toml`: configuración de Netlify (publica la carpeta raíz).

Para actualizar: sustituye `index.html` y Netlify publicará el cambio automáticamente.
